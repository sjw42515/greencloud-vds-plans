## 绿云 VDS 和普通 VPS 差在哪：独占核心是什么意思

一句话：普通 VPS 的 vCPU 是多人共享一颗物理核心，绿云 VDS 给你的核心是整颗物理核心归你用，不会因为邻居超卖而波动。

这是 EPYC NVMe KVM VDS 产品页白纸黑字写的：100% dedicated physical CPU cores, RAM and RAID-10 NVMe 4.0。CPU 用的是 EPYC Milan（Gen 3）与 Genoa（Gen 4），NVMe 4.0 组 RAID-10，端口统一 10Gbps，技术支持 24/7/365。控制面板方面，绿云常规产品线用的是 SolusVM（一键重装、rDNS、自动备份、快照、救援模式），周年庆特价系列则用 VirtFusion。

需要提醒两点边界：

1. **仅支持 Linux**。VDS 产品页没有任何 Windows 选项，想要 Windows 桌面环境的得看他家单独的 Windows VPS 产品线（月付 $10 起的不限流量系列）。
2. 独占核心解决的是 CPU 稳定性问题，不是网络问题。到中国大陆有没有直连优化，取决于机房和线路，跟是不是 VDS 无关，后面机房部分细说。

## 机房与线路：实测数据说了什么

绿云的网络底子是 4 大洲 30 个位置、32 个数据中心、600+ Gbps 聚合带宽，上游有 Arelion、NTT、IIJ、Telstra、Softbank 这些 Tier-1，2022 年起全网升到 10Gbps。到中国大陆的实际体验，得看具体机房的实测。

已有公开实测里最有参考价值的是东京机房（2023 年 3 月，2G/1核/20G SSD 机型）：电信、联通双程走 IIJ，晚高峰 22:18 测试三网整体优秀（电信偏远地区除外）；移动去程 CMI 转 Telstra，回程分方向走 IIJ 或 Telstra。Geekbench 5 单核 572 分、磁盘 I/O 370 MB/s，站长对那台 Xeon 机型的评价是“性能只能说一般”——注意那是 Intel 入门机型，和现在的 Ryzen/EPYC 系列不是一回事。该评测还提到 43.239.249.* 这个 IP 段比较干净，当时可解锁日本 Netflix 和 Disney+（流媒体解锁时效性强，仅供参考）。

其他机房的路由概况：越南机房自有 ASN、上游 FPT，电信回程走香港 FPT-CTG-Peer，联通回程绕美；加拿大机房有公开 Looking Glass（172.93.167.75）可自行测试。

一个值得记录的坑：2023 年绿云曾预售美国圣何塞 VPS，有站长购买后一个月开机，实际被分配到芝加哥机房。买特定城市机房时，开机后核对一下位置，有问题趁早期工单沟通。

## 真实总成本与隐藏限制：很多汇总文没讲清的部分

算账之前先看一条 many 汇总文会漏的规则。绿云的退款政策在条款里写得非常苛刻：

> 所有特价/促销套餐一律不退款；普通月付原价套餐仅 7 天内、且系统故障等苛刻前提下可申请；加密货币付款不退款。

这意味着 $123/三年的周年庆机、$15/年起的 Budget 特价机，付款即锁死，反悔无门。合理做法是先用普通月付机型小额试线路，确认延迟丢包满意后再上特价锁价。

接着算 VDS 的真实总成本。EPYCVDS-1 官方月付 $10，页面未展示年付折扣，按月付口径：

- 第 1 年：$120
- 第 3 年累计：$360

对比他家自己的套餐结构，$10/月的 VDS 和 $10/月的 RyzenKVM-2（1核 @3.5+GHz/2G/30G NVMe/2T）价格相同，差异在独占核心、8G 内存和 80G NVMe——前者多 6 倍内存和近 3 倍磁盘。如果你的负载只是博客、反代、探针，多花的钱买的是用不上的独占性；反过来跑 MySQL 主从、高频编译这类被 CPU 抖动坑过的业务，独占核心就是付这笔钱的全部理由。

隐藏限制还有三条，购买前最好知道：

1. **CPU 滥用规则**：连续 30 分钟以上 100% 占用 vCPU 会被限速或强行关机。批量转码、长时间压测、挖矿这类负载直接踩线，不适合。
2. **亚太流量减半是全系规则**，不止 VDS：SSDKVM-1 在亚洲给 750GB，美国给 1.5TB；EPYC Cloud Resources 的 $20 档 USA/EU 给 8TB、APAC 只给 3TB，差距 2.67 倍。业务流量大就优先美国/欧洲机房。
3. **SuperSaving Windows 套餐至少季付**，没有月付选项；部分香港节点对 China-direct 流量限速 10 Mbps。

另外注册购买时别开代理，绿云会触发欺诈拦截直接拦单——这是官方促销文案里明确提醒过的。

## 绿云适合谁、不适合谁

适合的三类人画像很清晰。第一是运维和折腾党：大盘鸡系列年付几十美元拿到 1TB～数TB SATA RAID-10，配 Rsync/Restic 做异地备份仓库，这是他家口碑最稳的用途。第二是吃单核和 IO 的中轻量业务：Ryzen 9 高频 + NVMe 对 WordPress、MySQL、高频 API 的动态处理有明显加持，VDS 系列则把 CPU 稳定性也补上了。第三是亚太本地化部署：总部在越南，对新加坡、香港、日本、越南机房的运营经验比较足，做东南亚受众的项目成本低。

不适合的也直说。对延迟丢包零容忍的强生产业务——金融行情、实时音视频、国内直连敏感的游戏服——绿云普通套餐是国际 BGP 路由，到大陆没有直连优化，晚高峰延迟和丢包会往上走；这类需求需要的是 CN2 GIA/AS9929 级别的精品直连，市面上有搬瓦工 CN2 GIA、DMIT 等专门做这个的商家（两者仅信息对比，无推荐路径）。长期跑满 CPU 的高耗能计算也避开，理由见上一节的滥用规则。

社区口碑方面提一下两面性：绿云曾在 LowEndTalk 评为最受欢迎商家 top5（官网亦自述获 Top Provider 奖项），但 V2EX 上也有用户发“建议永久拉黑”的帖子并详述自己 $25/月 的新加坡套餐体验，评价两极。机房多、价格低是共识，品控和售后预期需要放低一点。

## 常见问题

**绿云 VDS 支持退款吗？**
特价套餐一律不退款，普通月付原价套餐仅 7 天内且系统故障等苛刻前提下可申请，加密货币付款不退款。VDS 目前按官方页面为月付原价套餐，但下单前建议按“不可退”做心理预期。

**绿云 VDS 能装 Windows 吗？**
不能。EPYC NVMe KVM VDS 和 EPYC Cloud Resources 均仅支持 Linux，Windows 需选他家独立的 Windows VPS 产品线（月付 $10 起的不限流量系列，或 $90/月的托管型）。

**周年庆 $123/三年的套餐还能买到吗？**
2026 年 10 月官方在 LowEndTalk 明确：今年不办黑五，13 周年庆是本季唯一大型促销。库存动态刷新，未付款订单 30 分钟自动取消，想蹲补货需要提前登录账号备好付款方式。

**绿云日本机房到国内快吗？**
按 2023 年 3 月的公开实测，东京 IIJ 网络机型电信联通双程 IIJ，晚高峰三网整体优秀。但路由随时间变动，下单前建议用官方测试 IP（东京 103.121.210.3）自行 ping/mtr 验证当前状况。

**APAC 和 USA/EU 机房价格一样，选哪个？**
除流量外同档配置完全相同，而 APAC 流量减半（VDS $10 档：2TB vs 4TB）。业务面向国内或亚太用户选 APAC，流量大、受众在欧美就选 USA/EU。
